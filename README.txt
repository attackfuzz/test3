Blue Marble 地球儀 / メルカトル試作

1. index.html をブラウザで開きます。
2. NASA画像の直接読み込みが許可されれば自動表示します。
3. 読み込めない場合はNASA Blue Marbleの全球JPEGを端末へ保存し、
   「手元の全球画像を選ぶ」から選択してください。

内容:
- 左: Three.js球体に全球画像を貼付
- 右: 同じ画像を逆メルカトル式で再投影
- メルカトル表示範囲: 緯度 ±85.05112878°
- 地球儀: ドラッグ回転、ホイール/ピンチでズーム

NASA Blue Marble (January, 5400x2700):
https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-base/january/world.200401.3x5400x2700.jpg
